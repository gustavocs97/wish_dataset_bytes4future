# 04_results — Resultados

Outputs finais da análise — gráficos, prints e conclusões escritas.
É daqui que se seleciona o que entra nos slides.

---

## Estrutura

```
04_results/
├── charts/                 ← gráficos exportados do Python / Power BI
├── dashboard_screenshots/  ← prints do dashboard para os slides
└── key_findings.md         ← as 5–6 conclusões principais escritas
```

---

## key_findings.md

Cada conclusão tem:
- O número que a prova
- A coluna de onde vem
- Uma frase para o slide
